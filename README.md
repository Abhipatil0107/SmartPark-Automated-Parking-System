
# SmartPark — Automated Parking System

A Java 21 web-based parking management application.

## Features
- Live parking dashboard
- 10 parking slots
- Vehicle entry and exit management
- Automatic parking fee calculation
- Parking history and receipts

## Tech Stack
- Java 21
- Java HTTP Server
- HTML, CSS and JavaScript
- Docker

## Run Locally

```bash
javac ParkingSystem.java
java ParkingSystem
```

Open the URL printed in the terminal.
